# EchoBubbleLoop

Refactor de l'expérience AR audio en application React + Vite.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Fonctionnalités

- préparation avant immersion avec import audio et sélection de source ;
- HUD AR minimaliste avec auto-hide ;
- menu contextuel compact pour changer de mode, gérer la librairie et nettoyer la scène ;
- rendu spatial WebXR/Web Audio avec `three`.
